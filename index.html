데이터셋(dataset)

데이터셋이란 하나의 주제에 대한 여러 데이터들이 모인 집합이에요.

학습 목표

  • 데이터셋과 데이터베이스를 설명할 수 있다.
  • 서로 다른 데이터셋을 통합하는 데이터베이스의 필요성을 설명할 수 있다.

데이터베이스의 통합적 활용

데이터베이스 안의 각 데이터셋은 표 형태로 저장되며, 이를 테이블(table)이라 해요.

도서관 데이터베이스를 예로 들면, 책 목록 테이블·회원 명단 테이블·대출 기록 테이블이 공통 속성(도서관리번호, Member ID)을 기준으로 서로 연결돼요.

도서관리번호제목지은이출판사구입연도
354-2316오만과 편견제인 오스틴민음사2021
354-5672위대한 개츠비F. 스콧 피츠제럴드문예출판사2023

공통 속성으로 서로 다른 테이블을 연결하기

데이터베이스의 각 테이블에 저장된 데이터들은 공통적인 속성을 기반으로 서로 연결될 수 있어요. 예를 들어 위의 책 목록 테이블에는 이 책이 지금 대출 중인지 아닌지를 나타내는 속성이 따로 없어요. 하지만 이 책의 "도서관리번호(354-2316)"를 대출 기록 테이블에서 찾아보면, 그 책이 지금 대출되어 있는지, 언제 반납 예정인지를 확인할 수 있어요.

즉, 한 테이블에 없는 정보라도 공통 속성으로 다른 테이블과 연결하면 알아낼 수 있는 거예요. 이렇게 테이블끼리 연결해 주는 공통 속성을 키(key)라고 불러요.

기본키와 외래키로 테이블 연결하기

여러 테이블을 서로 연결하려면 각 행을 유일하게 구분할 수 있는 속성이 필요해요. 이런 속성을 기본키(Primary Key)라고 해요. 책 목록 테이블에서는 "도서관리번호"가, 회원 명단 테이블에서는 "Member ID"가 기본키예요 — 같은 값이 두 번 나오지 않으니까요.

대출 기록 테이블은 자기 것이 아닌, 다른 테이블의 기본키를 그대로 가져와서 "이 대출은 어떤 책이고, 누가 빌렸는지"를 나타내요. 이렇게 다른 테이블의 기본키를 참조하는 속성을 외래키(Foreign Key)라고 해요.

데이터베이스의 생활 속 활용 (CRUD)

데이터베이스는 기본적으로 추가(생성)·읽기·갱신·삭제 기능을 가져요. 흔히 영문 앞글자를 따 CRUD라고 불러요.

C
생성 Create

새 책이 들어오면 책 목록 테이블에 정보를 입력해요.

R
읽기 Read

제목·지은이 등 기준으로 저장된 데이터를 조회해요.

U
갱신 Update

책을 반납하면 대출 기록 테이블의 반납일을 수정해요.

D
삭제 Delete

오래된 책을 정리하면 목록에서 해당 데이터를 지워요.

기억할 점

  • 하나의 주제에 대한 데이터들의 집합을 데이터셋이라 하며, 대규모의 데이터셋들을 효율적으로 통합하고 관리하기 위해 데이터베이스를 사용한다.
  • 생활 속에서 이용하는 블로그, SNS, 온라인 쇼핑몰 등 대규모 데이터를 여러 사람이 공유하는 서비스들은 데이터베이스를 활용하여 데이터를 추가, 조회, 수정, 삭제하는 등의 작업을 처리한다.

2차시 · DB 설계 실습

나만의 쇼핑몰 데이터베이스 설계하기

오늘은 온라인 쇼핑몰의 데이터베이스를 처음부터 설계해요. 테이블 설계 → CRUD 연산 → SELECT·WHERE·ORDER BY·GROUP BY로 조회하고 분석하기, 4단계로 진행돼요.

STEP 1 / 4 · 어떤 테이블이 필요할까?

쇼핑몰 데이터베이스에 어떤 테이블이 필요할까요?

쇼핑몰은 "회원가입 → 상품 둘러보기 → 장바구니에 담기"까지 지원하려고 해요. 지금 단계에서 꼭 필요한 테이블만 골라보세요. (정답 개수는 정해져 있지 않아요 — 골랐으면 이유를 스스로 설명할 수 있으면 돼요.)

STEP 2 / 4 · 테이블 설계하기

학습지에 손으로 쓴 내용을 그대로 옮겨보세요

사용자·제품·주문정보 테이블에 5칸씩 미리 마련해뒀어요. 종이 학습지에 적은 속성명·설명·데이터형·조건(기본키/필수/블라인드)을 그대로 옮겨 적으면 돼요. 칸이 모자라면 "+ 속성 추가"로 늘리고, 안 쓴 칸은 "삭제"하면 돼요. 학습지에서 테이블을 4개로 나눴다면(예: 주문/주문상품) "+ 테이블 추가"로 늘려도 좋아요.

STEP 3 / 4 · CRUD 연산

직접 만든 테이블에 데이터를 생성·조회·수정·삭제해 보세요

각 테이블에 실제로 상품·회원 데이터를 몇 개씩 입력해 보세요. 필수 속성을 비워두거나 중복불가/기본키 속성에 이미 있는 값을 넣으면 오류가 떠요 — 다음 단계(조회 분석)에서 쓸 데이터를 최소 3~4행 이상 입력해 두세요.

STEP 4 / 4 · 조회하고 분석하기

SELECT · WHERE · ORDER BY · GROUP BY로 데이터 들여다보기

데이터베이스에서 원하는 정보만 뽑아보는 것을 조회(SELECT)라고 해요. 조건(WHERE)으로 걸러내고, 정렬(ORDER BY)하거나, 묶어서 집계(GROUP BY)할 수도 있어요. 아래에서 테이블을 고르고 직접 조회해 보세요.
